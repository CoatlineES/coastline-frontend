# Coastline - Plataforma Avanzada de Gestión y Visualización

Plataforma frontend de última generación para **Coastline**, diseñada para revolucionar la gestión comercial, operativa y la visualización técnica en el sector de impermeabilización y mantenimiento estructural de techumbres.

## 🚀 Características Principales

### 🏗️ Simulador 3D y Detección Estructural
- **Motor de Físicas Realista:** Simulación de clima dinámico en tiempo real (lluvia, tormentas, condiciones despejadas) utilizando HTML5 Canvas.
- **Escáner Interactivo de Techos:** Representación isométrica SVG hiperrealista con capas dinámicas para mostrar daños, detección de humedad y aplicación de geomembranas de reparación.
- **HUD Animado:** Interfaz de visualización de datos de diagnóstico estructurada con animaciones fluidas (`framer-motion`).

### 💼 CRM y Gestión Operativa Integrada
- **Panel de Control (Dashboard):** Visualización de KPIs y analíticas en tiempo real (proyectos, cuentas, contactos y negocios).
- **Gestión de Proyectos y Cotizaciones:** Flujos de trabajo interactivos para presupuestos, asignación de tareas y seguimiento de etapas de obra.
- **Módulo de Almacén e Inventario:** Control total sobre materiales y logística.

### 📄 Reportes y Certificaciones 
- **Generador de Reportes Técnicos:** Creación de reportes detallados (con mapas interactivos y fotos) del estado de las techumbres y trabajos de geomembranas.
- **Certificaciones PDF:** Sistema de exportación y previsualización de certificaciones de calidad y entrega de obra.

## 🛠️ Tecnologías Utilizadas

- **React 18** (con TypeScript)
- **Vite** como empaquetador ultrarrápido
- **Tailwind CSS** para un diseño moderno, responsivo y modo oscuro
- **Framer Motion** para transiciones cinemáticas y microinteracciones
- **HTML5 Canvas & SVG** para el motor de físicas (lluvia) y renderizado 3D de estructuras arquitectónicas.

## ⚙️ Requisitos e Instalación

1. Clona el repositorio:
   ```bash
   git clone [URL-DEL-REPOSITORIO]
   ```
2. Instala las dependencias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```
4. Abre [http://localhost:5173](http://localhost:5173) en tu navegador para ver la aplicación.
